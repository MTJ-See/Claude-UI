# Claude UI

Claude UI 是 Windows x64 桌面客户端。模型请求、会话接续和诊断操作均由本机的 Claude Code CLI 进程执行。应用使用 CLI 已配置的模型服务和认证。

## 开始使用

从源码仓库首次使用时，先在 Windows x64 PowerShell 中运行 `.\Build.ps1` 生成程序；仓库不包含编译后的 exe 或个人数据。核心模块和调用关系见 [核心文件与架构](CORE-FILES.md)。

双击 **ClaudeUI.exe**。左下角显示检测到的 Claude Code 版本。若未找到安装，可在 **CLI 工具** 中选择本机的 `claude.exe`，也可恢复自动查找。

- 在顶部选择工作目录。输入框内按 **Enter** 发送，按 **Ctrl + Enter** 换行，也可以点击 **发送**。回答会逐步显示。执行中可以停止，或打开执行日志查看输出、错误和退出状态。
- 输入框下方的 **添加文件** 支持多选本地文件，也可将文件拖入输入框，或复制文件后粘贴。截图复制到剪贴板后，在输入框中按 **Ctrl+V** 即可添加图片；普通文字仍按原方式粘贴。附件显示名称、大小和图片缩略图，可在发送前移除，也可只发附件。每条消息最多 10 个附件、总计 30 MB，单文件最多 20 MB，单张图片最多 5 MB。PNG、JPEG、GIF、WebP 以图片内容随消息发送；BMP、TIFF 和剪贴板截图转换为 PNG。图片理解需要所选模型支持视觉能力。其他文件由 CLI 根据消息中的本地副本路径使用工具读取，工具授权沿用当前权限模式；文件解析能力取决于 CLI 工具和本机环境。
- 附件副本保存在 `程序所在目录的 Data\attachments`，原文件修改或移动不影响已添加的副本。附件草稿按会话隔离并保存，发送后的附件记录及预览随聊天保存；移除草稿附件只取消本次发送，保留缓存副本，避免影响已有记录。当前版本不自动清理附件缓存。
- 对话中的 Markdown 表格与 CLI 格式化结果中的竖线表格由本地渲染器排版，支持表头、分隔线、交替底色、列对齐和单元格自动换行。流式输出与重新打开历史回复均可显示；代码块保留原样，原始回复和原始日志不变，排版不调用模型。
- 每条 Claude 回复下方显示本轮调用过程：实时阶段、推理力度、模型与已用时间。结束后保留总耗时和本地完成时间，展开 **执行过程** 可查看思考、生成回复、工具调用和授权等待的阶段记录。耗时从本轮 CLI 启动开始计算，包含工具执行与等待时间；这些信息随会话保存，旧回复不会补写估算数据。
- 回复下方的模型信息后展示本轮 **请求 ID**，支持鼠标拖选、Ctrl+C 或右键复制；一轮中的多个请求逐行显示，并随回复保存。请求统计的 ID 列按完整内容展开，选中记录后，下方还会展示自动换行、可复制的完整 ID。旧回复未保存的 ID 不伪造补写。
- 请求统计页支持勾选每行左侧复选框后 **删除选中**，点击行可累加选择，重复点击已选行或复制请求 ID 不会取消选择，Shift 点击可连续选择；取消请取消勾选或点击“取消选择”。提供 **全选当前结果**、**取消选择** 和已选条数，筛选或刷新后保留仍可见的选择。**清空全部统计**，确认后同步删除本地记录并更新汇总。清空全部不受筛选条件限制；聊天、回复中的请求 ID 和 CLI 会话保持不变。删除后仍可继续记录新请求。
- **模型配置** 保存显示名称和模型 ID，也可填写 Anthropic 兼容 API 基础地址和凭据。支持 Bearer Token 和 x-api-key；自定义地址使用 HTTPS，本机回环地址可使用 HTTP。凭据只在本机用 Windows 当前账户加密保存。
- 在模型配置窗口点 **测试连接**，可以用当前填写的配置发送一条简短请求。测试会产生少量 token 用量，配置通过 **保存配置** 单独保存。
- **模型配置 → 上下文缓存** 可沿用 CLI（默认）、显式启用 5 分钟或 1 小时缓存，或为不兼容端点禁用缓存。缓存保留完整输入，降低重复计算和相应费用，不缩短上下文 token 数；1 小时写入较贵。请求统计详情显示实际缓存命中占比。选型、适用范围、限制与离线验证见 [输入 Token 优化评估](TOKEN-OPTIMIZATION.md)。
- 从发送按钮旁的下拉框为当前会话选择模型。**本机默认**沿用现有 CLI 配置；自定义端点只对该次 CLI 请求生效。继续已有会话时，CLI 会把已有上下文交给选中的模型。模型接入使用 Claude CLI 支持的 Anthropic 兼容接口。
- 在 **参数设置** 中可设置推理力度、权限模式和最大轮数。**接受编辑** 会根据 CLI 的权限规则自动接受文件编辑。
- Claude CLI 请求工具授权时，窗口右下角会显示工具名称和参数。选择 **仅授权本次** 后继续当前请求，选择 **拒绝并终止** 后结束本轮。CLI 的明确禁用规则仍然生效。
- 自动压缩由 Claude CLI 的配置决定。已有长对话可从最近对话菜单选择 **压缩上下文**，也可发 `/compact` 加可选的摘要重点。压缩会调用模型生成摘要，之后继续使用同一个会话。
- 左侧 **项目** 汇集本机 CLI 记录中的项目文件夹，展开文件夹可查看其会话。点 **项目** 旁的 **+** 选择电脑中的项目文件夹；文件夹行右侧的编辑图标可在该项目中新建对话。同名文件夹可通过悬停查看完整路径。
- 项目文件夹行右侧的 **⋯**（或右键项目名称）提供 **置顶 / 取消置顶、编辑、归档聊天、移除项目**，不提供分区。编辑只修改项目显示名称；置顶将整个项目排在前面；归档隐藏项目分组，可从 **项目** 旁的 **已归档** 入口恢复；移除只隐藏该项目，通过添加相同文件夹可重新添加。全部会话仍保留在全局对话列表中，文件和原工作目录保持不变。项目下会话菜单提供压缩上下文、重命名、创建分支、复制会话 ID 和从对话列表移除，使用统一的图标样式；点击会话记录即可打开并接续会话。
- 左侧 **对话** 展示全部已发现的 CLI 会话与客户端对话，默认展开，再点标题即可收起。项目和对话的展开状态会保存。点击会话可读取原有聊天内容并接续指定会话；已移除的文件夹仍显示历史记录，但需要恢复目录后才能执行任务。
- 启动、回到应用以及空闲时会刷新本机 CLI 记录，读取当前、用户默认、已知旧配置目录及客户端曾记录的配置目录；不调用模型。新增 CLI 会话会自动出现在列表中。
- 读取历史时，根据 CLI 的内部命令上下文过滤重命名等本地操作及其输出，避免把内部 XML 显示成“我的消息”或会话标题；真正发送的文字、XML 示例和斜杠命令保留。启动时会重新读取当前 CLI 会话，纠正旧版缓存中的这类显示记录；CLI 原始会话文件保持不变。
- 恢复 CLI 历史时，附件、环境快照等非显示记录也参与历史链回溯，避免把它们误当成历史终点。导入按消息顺序合并，保留已有消息、重复问答、附件、耗时和客户端提示；CLI 文件暂不完整时不会用片段覆盖本地聊天。旧版因历史链中断而漏显的内容，会在重新打开会话时从仍存在的原始 CLI 记录中补回。
- 同一轮请求中，Claude 调用工具前的说明与工具执行后的结论合并显示为一条回复，段落内容全部保留。真正的下一条用户消息开始新一轮；旧缓存中拆开的回复会在打开会话时合并，并匹配实时流式回复，避免导入时重复显示，已有执行过程信息保留。
- 已有会话会记住所属 Claude CLI 配置目录。对于旧版本留下的条目，应用通过 CLI 检查当前配置和本机旧配置目录，找到会话后再接续。
- 对话的 **⋯** 菜单和右键菜单提供压缩上下文、重命名、创建分支、复制会话 ID 和从列表移除（不删除 CLI 原始会话）。重命名和分支由 Claude CLI 执行。分支保留原会话上下文，后续消息写入新会话。移除需要确认，只清除 Claude UI 自己保存的记录。普通 CLI 会话没有逐条永久删除的命令。
- **CLI 工具** 提供版本、安装健康诊断、登录状态、MCP 服务、插件、后台任务和本机命令帮助。点击 **版本** 会重新检测当前 CLI，并从 npm 官方 registry 获取 Claude Code 的 `latest` 版本；发现新版后显示本机版本、最新版本、安装位置和更新命令，选择 **是** 才下载更新，选择 **否** 保留当前版本。npm 安装使用对应 Node.js / npm 并明确指定原安装目录；原生安装运行 `claude update`，WinGet 安装交给 WinGet。更新日志实时显示，结束后重新运行当前 CLI 检查版本，只有达到目标版本才显示成功，并刷新左下角版本。网络错误、权限不足、更新通道或版本限制会显示失败原因，可稍后重试；检查和更新期间可点击停止。检查最新版本不调用模型。执行结果采用独立命令栏、状态标签和文档式输出，底部显示耗时与退出码。可切换 **原始日志**，**复制输出** 始终复制原始日志。未配置 MCP 服务时显示配置提示。MCP 列表会按 Claude CLI 的规则检查已批准服务的连接。
- **模型计费标准**：进入 **请求统计 → 模型计费标准**，没有请求记录也可新增规则。支持任意模型标识（含 DeepSeek）、可选网关范围、按 Token / 按次计费、单价、计费单位、USD / CNY 及启用状态。按 Token 可分别设置未缓存输入、缓存写入、缓存命中输入及输出单价，单位支持 1 / 1,000 / 1,000,000 Token。选择已有规则可编辑，取消勾选启用并保存即可停用。可选峰谷价格按北京时间周一至周五 09:00–12:00、14:00–18:00 生效；周末及手动维护的节假日日期使用空闲价格。每轮执行启动时固定计费规则，执行期间的修改从下一轮生效；历史金额、币种和单价快照保持原值。USD 与 CNY 原币展示、分别汇总，不做固定汇率转换。
- **请求统计** 按请求记录模型、网关、输入/输出与缓存 Token、费用分项、耗时、状态和完成时间；对话、压缩及连接测试共用采集入口。支持请求/执行 ID、模型、日期、状态及当前会话的组合筛选。网关实际扣费与参考估算分开汇总，配置计费优先匹配指定网关与模型的规则，再匹配适用于全部网关的模型规则；响应模型无匹配规则时，使用本轮请求模型标识按相同网关优先级匹配，以支持网关模型别名；没有配置时才采用内嵌 LiteLLM 开源参考价格。停用、配置冲突或配置无效时显示原因，不回退到其他费用。未知模型和不完整数据不猜费用，旧记录保持原值。事件耗时不含首字等待，执行总耗时包含等待；详情明确注明口径。选型、依赖、调用链、数据结构与配置见 [请求看板说明](REQUEST-OBSERVABILITY.md)。
- 拖动侧边栏右侧边缘可调整宽度，松开后自动保存。缩小窗口时会限制侧栏宽度，为聊天区域保留空间；放大后恢复偏好宽度。
- 右上角可切换深色与浅色主题。应用把主题、参数与 GUI 对话记录存放在 `程序所在目录的 Data\state.json`。CLI 自己管理凭据、设置与会话文件。

## 界面风格

界面参考 Notion 官网的黑白视觉语言：纸白内容区、浅灰侧栏、黑色主按钮与文档式对话排版。深色主题使用对应的中性灰配色。新对话首页提供 **梳理项目**、**检查代码**、**拆解任务** 三个入口，点击后将提示词填入输入框，可编辑后发送。

## 源码

运行需要 Windows x64 自带的 .NET Framework 4.x 桌面运行库，以及已安装的 Claude Code。可在 PowerShell 中执行 `./Build.ps1` 重新编译，使用 `./Build.ps1 -Smoke` 运行本地验证。带 `-Live` 的验证还会用现有 CLI 配置向模型发送两条合成消息，验证流式响应、重命名、分支和会话接续。

| 文件 | 职责 |
| --- | --- |
| `src/MainWindow.xaml` | 窗口布局与控件样式 |
| `src/MainWindow.cs` | 对话、工具页、参数与执行状态 |
| `src/CliConversationCatalog.cs`、`src/SidebarNavigation.cs` | 本地 CLI 会话发现、历史读取与项目导航 |
| `src/CliHistoryMerge.cs` | CLI 历史与客户端缓存的有序合并，保留已有消息及其元数据 |
| `src/ClaudeCli.cs` | CLI 定位、参数、可扩展命令表、子进程与停止 |
| `src/CliUpdate.cs` | 本机版本检查、最新版本查询、安装方式识别与更新命令 |
| `src/ClaudeStream.cs` | 解析 Claude CLI 的流式 JSON、执行阶段与错误信息 |
| `src/ReplyProgress.cs` | 回复内的实时过程、阶段记录、耗时与完成时间 |
| `src/AppData.cs` | 应用状态、最近对话与主题资源 |
| `src/ModelProfile.cs`、`src/ModelProfilesDialog.cs` | 模型配置、凭据存储和 CLI 路由 |
| `src/PromptShortcuts.cs` | 输入框的发送与换行快捷键 |
| `src/ChatAttachment.cs` | 附件副本、大小限制、图片编码、消息内容和预览 |
| `src/RequestStatistics.cs`、`src/RequestStatisticsView.cs` | 请求用量、费用估算和本地统计视图 |

添加只需固定 CLI 参数的按钮时，在 `CliAction.All` 中增加命令、名称与说明。按钮、运行状态、输出和停止行为会沿用现有工具页。

## 本地数据目录

客户端数据统一保存在 ClaudeUI.exe 所在目录的 Data 文件夹，包括 state.json、request-statistics.jsonl 和 attachments。首次升级启动自动复制旧 C 盘应用数据并更新附件记录的路径，旧目录保留为备份；已有 Data\state.json 时不重复迁移。目录需要可写，失败会提示错误，不回退到 C 盘。移动程序请一并移动 Data；凭据仍绑定原 Windows 用户。Claude CLI 自己管理的配置、凭据与原始会话目录不受此改动影响。
